# IA MAKER 4 — Tutorial Dia 1

Tutorial interativo do workshop **IA MAKER 4**, focado em criação de animações 3D profissionais com IA generativa. Página única, em português, pensada para ser acompanhada durante e depois do workshop.

## O que é

Um guia de referência com os conceitos, processos e prompts ensinados no Dia 1 do workshop: dos 4 tipos de IA até um pipeline de criação profissional, passando por criação de personagens, estilos de animação e storytelling visual.

## Como usar

Acesse a página publicada pelo GitHub Pages e navegue pela barra lateral:

1. **Checklist rápido** — marque os conceitos conforme for praticando.
2. **Módulos 01 a 12** — o conteúdo do workshop, em ordem:
   - 01 · Introdução e motivação
   - 02 · Tipos de IA e limitações
   - 03 · Qualidade e critério
   - 04 · As 9 camadas de qualidade
   - 05 · Segredo do prompt perfeito
   - 06 · Gerar resultado e vender
   - 07 · Pipeline de criação profissional
   - 08 · Criação de personagem
   - 09 · Estilos de animação
   - 10 · Enquadramento
   - 11 · Storytelling visual
   - 12 · Próximos conteúdos
3. **Banco de prompts** — os prompts do PromptBoss prontos para copiar.
4. **Ferramentas** — todas as IAs mencionadas no workshop, com tipo e uso.
5. **Links úteis** — slides e outros materiais de apoio.

O progresso de leitura é marcado por uma barra no topo da página, e as marcações do checklist ficam salvas no navegador.

## Estrutura

```
ia-maker-4-tutorial/
├── index.html              # página inteira (conteúdo, estilo e interação)
└── .github/workflows/
    └── pages.yml            # deploy automático para o GitHub Pages a cada push em main
```

Não há build nem dependências — é HTML, CSS e JavaScript puro em um único arquivo.
