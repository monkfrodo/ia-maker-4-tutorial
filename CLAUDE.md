# ia-maker-4-tutorial

## O que é
Tutorial interativo de página única (single-page) do workshop "IA MAKER 4 — Dia 1", sobre criação de animações 3D com IA generativa: 12 módulos, checklist de prática, banco de prompts, lista de ferramentas e links úteis.

## Stack
- HTML + CSS + JavaScript puro, tudo em um único `index.html` (sem framework, sem build)
- Google Fonts: Bebas Neue, Inter, JetBrains Mono

## Deploy
GitHub Pages, com deploy automático via GitHub Actions (`.github/workflows/pages.yml`) a cada push em `main`.

## Estrutura
- `index.html` — página inteira: header, sidebar de navegação, checklist rápido, módulos 01–12, banco de prompts, ferramentas e links úteis
- `.github/workflows/pages.yml` — pipeline de deploy para o GitHub Pages

## Convenções
- Commits em inglês, conventional commits, sem Co-Authored-By
